## Color Scheme Reference

### Light Mode
- **Background**: #f7fafc (very light gray-blue)
- **Cards**: #ffffff (white)
- **Hero Gradient**: #3182ce → #2c5aa0 (blue gradient)
- **Text Primary**: #2d3748 (dark gray)
- **Text Secondary**: #718096 (medium gray)
- **Accent**: #3182ce (HobbyTrack blue)

### Dark Mode
- **Background**: #1a202c (dark blue-gray)
- **Cards**: #2d3748 (medium gray)
- **Text Primary**: #f7fafc (very light gray)
- **Text Secondary**: #a0aec0 (light gray)
- **Accent**: #63b3ed (lighter blue)

## Interactive Elements

### Hover Effects
- **Cards**: Subtle lift (2px up) + enhanced shadow
- **Action Buttons**: Slide right 4px + color change
- **Media Items**: Scale 1.05x + shadow
- **Quick Actions**: Background change + icon color shift

### Loading States
- **Skeleton Animation**: Shimmering gradient effect
- **Progressive Loading**: Cards animate in with stagger
- **Image Placeholders**: Gray rectangles with icon

## Typography Scale
- **Hero Title**: 2rem (32px) - Bold
- **Card Titles**: 1.25rem (20px) - Semi-bold  
- **Stats Numbers**: 1.75rem (28px) - Bold
- **Body Text**: 0.875rem (14px) - Regular
- **Metadata**: 0.75rem (12px) - Regular

This visual mockup demonstrates how the Personal Dashboard will provide an engaging, motivational experience that encourages users to continue their hobby projects while maintaining the clean, professional aesthetic of the HobbyTrack application.
